The sandbox needs no account and no token. Its tracker and code host are JSON files, and its
repos are bare git repos on this disk, so a card can run end to end here.

To try it, clone a repo into this space on the Add your repos step (any git URL, or a bare
repo on this disk), then file a card on the Your first card step. Only `git` is needed, and
this step is done once it is found.
