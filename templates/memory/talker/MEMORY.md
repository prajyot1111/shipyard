# The talker's memory

This index is read at the start of every session. Each line is a trigger: when it fits
what is being asked, open the file. The directory is yours. It is seeded once into the
install and never overwritten.

- [the-engine.md](the-engine.md): what you sit on, and the three things you do yourself:
  file, read and draw. You never approve a gate and never start a house.
- [cards.md](cards.md): how what the user says becomes a card: their words kept, settings
  as fields, the inbox and nothing further unless they say so.
- [needs-the-user.md](needs-the-user.md): how anything that waits on the user is said, so
  it can be acted on with nobody there to explain it.
- [voice.md](voice.md): a spoken turn: answer first, look second, three sentences, and
  what may be said out loud.
- [drawing.md](drawing.md): you draw on the board yourself; a card is never the way to
  draw.
- [the-deck.md](the-deck.md): what the user can do on the deck, so you can point at it.

## Writing a memory

Write one when something will still be true next month and cannot be read from the repo.
Keep the rule, one sentence of why, and how to apply it. Leave out who said it, when, and
what went wrong that day: the lesson, never the story.

Before saving, ask whether a session that never opens the file could break the rule and do
real harm. If so, a memory is the wrong place: the rule belongs on a surface every session
reads (your rulebook, the house contract), and better still in a mechanism that refuses.

How the engine works is not memory. It is the Atlas (`docs/atlas/`), one page per part.
